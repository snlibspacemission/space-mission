# 우주탐사대원 훈련 미션

중원어린이도서관 우주체험관 전시물 QR 퀴즈 미션 페이지입니다.
아이들이 전시물 옆 QR 코드를 찍어 문제를 풀고, 암호 조각을 모아
9곳을 모두 통과하면 수료증과 비밀 암호가 나타납니다.

- 서버·데이터베이스 없음 (진행 기록은 아이 휴대폰 브라우저에만 저장)
- 개인정보 수집 없음
- GitHub Pages로 무료 공개
- **매달 자동으로 문제가 바뀜** (11월이면 `data11.js`)

## 파일 구성

| 파일 | 역할 | 고칠 일 |
|---|---|---|
| `js/sets/data1.js` ~ `data12.js` | **월별 문제·정답·힌트·비밀 암호** | 문제를 바꿀 때 |
| `js/config.js` | 정거장 코드(QR), 이름, 월 선택 방식 | 거의 없음 |
| `index.html` | 아이들이 보는 미션 페이지 | 없음 |
| `qr.html` | 직원용 QR 인쇄 + 월별 미리보기 | 없음 |
| `js/loader.js`, `js/app.js`, `css/style.css` | 동작과 디자인 | 없음 |

## 월별 세트 운영

- `config.js`의 `set: "auto"` → 오늘 날짜의 달 세트를 자동 사용
- 특정 세트를 고정하려면 `set: 3`처럼 숫자로 바꿉니다.
- 달이 바뀌면 아이들의 진행 기록도 자동으로 새로 시작됩니다.
- 정거장 코드는 모든 달이 같으므로 **QR은 한 번만 인쇄**하면 됩니다.

## 직원 미리보기

`qr.html` 위쪽의 1월~12월 버튼을 누르거나, 주소 끝에 `?set=5`를 붙이면
5월 세트를 미리 풀어 볼 수 있습니다. 화면 위 빨간 띠의 '미리보기 끝내기'를 누르면
원래대로 돌아갑니다. 미리보기 기록은 실제 운영 기록과 따로 저장됩니다.

## 문제 바꾸기

해당 달 파일을 열어 `question`, `answer`, `wrong`, `hint`, `explain`, `find`를 고칩니다.

- `secretWord`는 3~9글자로 자유롭게 정할 수 있습니다.
  9글자보다 짧으면 정거장에 고르게 나눠 주고, 나머지는 ⭐ 별 에너지가 됩니다.
- 특정 정거장에서 줄 글자를 직접 정하려면 그 문제에 `"piece": "글자"`를 적습니다.
- 문제 순서는 정거장 1~9 순서와 같아야 합니다.
